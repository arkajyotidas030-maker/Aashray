# Claims we can and cannot make

Labels used in the product: **LIVE / STATIC / FUSED / RULE / SIMULATED / PRECOMPUTED / OPTIONAL LLM**.

## Safe for judges

- Evidence is not an incident; nearby reports can fuse into one cluster with **cluster confidence** (not field accuracy).  
- Critical alerts need corroboration.  
- Isolation is last-road graph reachability, not pin distance.  
- Fast path through the hazard polygon is rejected; remaining lowest-duration packed route is labelled safest available.  
- Unconfirmed safety status counts **simulated registered users** who have not checked in — not missing persons.  
- The pipeline runs with `health.llm = down` and `health.routing = precomputed`.  
- Assign/dismiss only changes a demo incident status.

## Do not claim

- Scientific landslide nowcast or “this slope will fail.”  
- Live IMD / CWC / official government feeds.  
- Real NDMA / SDRF / 112 dispatch.  
- Real SMS (DLT) delivery.  
- Live Google or OSRM driving directions (packed polylines only).  
- Missing-person detection from silence.  
- Production-grade offline mesh or queued SOS when the network is dead (SMS card is copy-only).  
- Photo computer vision (optional file is stored; no auto tags).  
- Multi-hazard national coverage.
